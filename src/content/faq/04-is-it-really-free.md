---
question: "Is the software really free? What's the catch?"
section: "The basics"
order: 4
---
Yes, really. The software will be available under a standard open-source license that permits anyone to download it, run it, modify it, and use it commercially, with no fee owed to the Collective ever. This is not a trial, not a starter tier, and not a feature-limited version. It is the actual platform.

The closest thing to a catch is that open-source software has no built-in support contract. If you download it and run it yourself with no help, you are responsible for installation, configuration, maintenance, and troubleshooting. This is exactly how most open-source software works. The Collective will publish documentation, host a community where users can help each other, and, over time, maintain a list of certified vendors who provide paid implementation and support services for organizations that want them. The software itself remains free; paid help is optional.
