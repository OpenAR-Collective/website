Mission Supporter roster entries live here, one JSON file per organization.
The /supporters page sorts them alphabetically by name and renders all
organizations on identical terms, per the Community Programs and Standards
Policy, Section 4.5.

File format (filename: a short slug, for example acme-recovery.json):

{
  "name": "Acme Recovery Services",
  "website": "https://example.com",
  "logo": "/assets/supporters/acme-recovery.png"
}

"website" and "logo" are optional. Logo files go in public/assets/supporters/.
Only add organizations whose signed Statement of Support has been verified in
CiviCRM and approved for publication.
